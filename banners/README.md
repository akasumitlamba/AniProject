# AniHome Banner Store

159 named landscape banners (including 129 curated mainstream apps).

Named landscape artwork for AniHome, prioritising entertainment, games and tablet-friendly creativity, learning, reading and productivity. The catalog also includes utilities and India-relevant shopping/payment apps.

- `catalog.json`: app names, aliases, package/host matches, categories, priorities and image checksums.
- `images/`: one 1.62:1 banner per app, named with lowercase app-name hyphens.
- `sources.json`: official identity references.
- `generation.json`: prompts used for new artwork.
- [CONTRIBUTING.md](CONTRIBUTING.md): complete guide for people and AI agents.

In AniHome, long-press an existing tile → Choose tile image → Banner Store. Matching artwork appears first. Tablet favourites prioritises entertainment/tablet apps; All apps and search expose the full catalog. Tap a banner to preview and adjust the crop; Use tile image saves it. Gallery and the copyable AI prompt remain alternatives.

The app bundles this folder for offline browsing. Explicit Refresh loads the public `akasumitlamba/AniProject` catalog anonymously; no GitHub token or account is required. Cached and bundled artwork remains available if a request fails. Third-party logos remain their respective owners' marks.

Individual official references are recorded in `sources.json`. The catalog is curated, not an asserted live popularity ranking.
