# Technical contributor instructions

Read PROJECT-CONTEXT.md and CONTRIBUTING.md before changes. Work only on the requested product: AniHome is the launcher; AniBrave owns browser profiles and watch tracking.

Use the documented toolchains and run relevant tests, lint and source privacy checks. Public banner updates are anonymous and use AniProject; preserve offline fallbacks, bounds and content verification.

Preserve package IDs, app data and signing identity for compatible updates. Signing material stays outside Git. Use synthetic fixtures for public screenshots and diagnostics. Do not add private conversations, personal-device details, local paths or maintainer diaries to technical context.

Keep upstream licenses and attribution intact. Do not import another repository's history or private metadata into this public source tree.
