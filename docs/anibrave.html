AniBrave

Pick up the episode you were watching. Keep your speed and viewing mode set for each site.

Download AniBrave APK Explore features

Set up your viewing.

  • Episode memory

    Return to your episode and timestamp on supported sites. Your watch history stays on your device.

  • Speed by site

    Set a playback speed once and reuse it when you return to that site.

  • Vertical tabs and site views

    Switch tabs in a sidebar. Save Mobile, Desktop or a desktop identity with a mobile layout per site.

  • Fullscreen shortcuts

    Pin a website to AniHome and open it fullscreen without the address bar.

AniBrave is an independent customisation of Brave, not an official Brave product.
